# 模拟运营巡检 SOP：门店异常核查

用途：用于购物中心经营风险预警 Agent 的 RAG 演示。

## 巡检触发

以下情况建议触发巡检任务：销售环比下降超过 20%，进店率低于 5%，成交转化率低于 8%，水电费波动低于 -20%，近 90 天投诉数达到 4 次以上。

## 巡检内容

巡检应核查门头和橱窗陈列、店内货架饱满度、导购在岗情况、收银系统运行、营业时间、促销露出、顾客投诉记录和同区域竞品变化。

## 儿童配套专项

儿童配套商户应额外核查安全巡检分、退款申请数、续费率和家长投诉率。安全巡检分低于 82 分或家长投诉率达到 5‰ 时，应优先进入运营复核。

## 输出要求

巡检结论不得只写“正常”或“异常”，必须给出观察事实、照片或记录编号、责任人、建议动作和复核时间。
