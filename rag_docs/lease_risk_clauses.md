# 租赁合同条款样例：经营与履约风险

用途：作为经营风险智能决策 Agent 的 RAG 知识模板，用于经营异常、租售比压力和合同履约边界提示，不构成正式法律文本。

## 经营异常观察

当商户连续出现销售环比下降、进店率下降、成交转化率下降或水电费异常下降时，运营团队应先确认是否存在装修、短期闭店、系统误差、促销节奏变化或楼层整体客流波动。

## 水电费异常

水电费较上期下降超过 20% 时，建议由楼层经理进行营业状态核验。下降超过 40% 时，应重点排查缩短营业、低库存运营、撤店准备或实际停业风险。

## 租售比压力

租售比达到 18% 可进入观察区间；超过 25% 可视为租赁成本压力较高；超过 35% 时，需结合销售额、客流、毛利结构和品牌定位进行专项约谈。

## 整改闭环

经营约谈应形成记录，至少包括异常原因、商户解释、整改动作、责任人、截止时间和复核日期。未按期提交整改记录的商户，风险等级可在下一轮复核中上调。
