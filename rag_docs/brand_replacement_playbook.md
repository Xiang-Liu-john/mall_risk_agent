# 模拟招商替换与品牌备选策略

用途：用于购物中心经营风险预警 Agent 的 RAG 演示。

## 触发条件

出现极高风险、长期欠费、保证金覆盖率不足、销售持续下滑且整改无效时，招商团队可启动备选品牌库准备，但不得直接替换现商户。

## 备选品牌筛选

备选品牌应优先匹配同楼层客群、同业态定位、相近铺位面积和租金承受能力。对于餐饮业态，应关注翻台效率、外卖占比、排烟条件和食品安全记录。对于儿童配套，应关注安全合规、师资稳定、续费能力和客诉处理能力。

## 决策资料

招商预案至少包含：当前商户风险摘要、铺位经营数据、同楼层空铺影响、候选品牌清单、预计租金水平、装修周期、切换成本和审批路径。

## 审批边界

招商替换属于重大经营动作。Agent 可以生成备选品牌分析和审批材料草稿，但不能自动向现商户发送终止合同通知，也不能自动承诺新品牌入驻条件。
